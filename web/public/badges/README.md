# Move-review badges

These badge SVGs are Chess.com's published move-classification artwork, mirrored
from:

```text
https://www.chess.com/bundles/web/images/color-icons/
```

They are bundled so game reviews render fully offline. The SVGs are
self-contained (colour and shape are baked in) and are served from `/badges/`
by the web app.

## Included assets

Classification badges (the app currently uses all except `book`, `miss`, and
`missed-win`):

- `classification-brilliant.svg`
- `classification-great-find.svg`
- `classification-best.svg`
- `classification-excellent.svg`
- `classification-good.svg`
- `classification-book.svg`
- `classification-inaccuracy.svg`
- `classification-mistake.svg`
- `classification-blunder.svg`
- `classification-miss.svg`
- `classification-missed-win.svg`
- `classification-forced.svg`
